## Release v1.5.0 - Resource Monitoring & Beginner-Friendly Experience

### 🚀 New Feature: Resource Monitoring
- **Container Resource Monitoring**: New `dcutil stats` command provides real-time and detailed resource monitoring
  - `dcutil stats` - "Is my code using a lot of resources?" (Quick snapshot)
  - `dcutil stats watch` - Monitor live while running tests/builds
  - `dcutil stats detailed` - "Am I hitting my memory limit?" (Full details with limits)
  - `dcutil stats top` - "What programs are actually running?"

### 🎯 Project-Wide Beginner-Friendly Redesign
- **No Docker Knowledge Required**: Completely rewritten all user-facing messages to eliminate container jargon
- **Plain Language Throughout**: Commands now use "development environment" instead of "devcontainer" or "container"
- **Helpful Error Messages**: Every error explains what happened and shows the exact command to fix it
- **Friendly Prompts**: All interactive messages are clear, encouraging, and action-oriented
- **Updated Help System**: Main help and all subcommands now focus on what you want to do, not Docker terminology
- **README Overhaul**: Introduction emphasizes ease of use and zero Docker expertise needed

### 🎨 Command-Line UX Enhancements
- **Interactive Menu**: Run `dcutil` (no arguments) to see a friendly menu with 9 common tasks
- **Smart Suggestions**: Typos get "Did you mean?" suggestions using fuzzy matching (e.g., "stauts" → "status")
- **First-Run Welcome**: New users see a helpful guide with quick start steps (shown once)
- **Contextual Tips**: Get hints based on environment state:
  - After `dcutil init` → "Next: Run 'dcutil up' to start your environment"
  - After `dcutil status` → Different tips based on whether environment is running/stopped
- **Time Expectations**: Clear messages for long operations:
  - "⏳ This may take a few minutes on first run..." (dcutil up)
  - "⏳ This may take several minutes depending on the image size..." (dcutil build)
  - "⏳ This may take a few minutes depending on the features..." (dcutil features install)
- **Enhanced UX Module**: New `lib/ux.sh` with comprehensive helper functions

### 🎨 Stats Command Design Philosophy
- **Contextual Help**: Inline tips like "High CPU (>80%)? Your code might be processing-intensive"
- **Visual Clarity**: Uses emojis and formatting (📊, 💡, ⚠️, ✓) to make output easy to scan
- **Plain Language Explanations**: Every metric is explained in beginner-friendly terms
- **Real Questions Answered**: Designed around questions developers actually ask

### 🎯 Real-World Use Cases
```bash
# Before running tests - check baseline
dcutil stats

# During a build - watch resources in real-time
dcutil stats watch

# After getting "out of memory" error - investigate
dcutil stats detailed

# When things feel slow - see what's running
dcutil stats top
```

### 🛠️ What You Can Monitor
- **CPU Usage** - "Is my code doing heavy work right now?"
- **Memory Usage** - "Am I running out of RAM?"
- **Network I/O** - "How much data am I sending/receiving?" (web apps)
- **Disk I/O** - "How much file reading/writing is happening?"
- **Active Processes** - "What's actually running in there?"
- **Resource Limits** - "Am I close to hitting configured limits?"
